February 1

During this week, we focused on laying the foundation for our project. This included bringing the group together, building team rapport, and carefully reviewing the project specifications to ensure a clear understanding of the requirements.

We selected Data Science and Computer Science as our primary majors, with English and Economics as the chosen minors.

We also began planning how to structure course offerings by compiling data from Fall 2020 to the present into a MySQL database. In addition, we started setting up the database and outlining how user data (such as usernames and passwords) would be managed.

February 8

This week, we continued developing the visual interface of the website, focusing on layout and usability.

We also began inserting values into the database tables we created and established a file scaffold to support future development and organization of the project.

February 15

This week, we began adding weekly updates to the GitHub Pages website while also getting the login page functional on the project site.

Additionally, each team member created an individual design prototype for the final website, helping guide the overall visual direction of the project.

February 22

This week, all database tables were created and we began inserting values for testing, including course data.

On the design side, we produced the first combined prototype by merging elements from each team member’s individual designs into a single cohesive layout.

March 1

This week, we implemented CSS styling for the website and created dedicated hub pages for each of the three user types.

We also began working on the logout functionality while continuing to populate database tables and define relationships between them.

March 8

This week was primarily focused on preparing the midterm report. As a team, we collaborated to make significant progress on the document and ensured it would be completed before the submission deadline.

March 29

This week, we began implementing the password change procedure and continued development of the logout functionality.

We also conducted extensive testing of the login system, applying concepts from the testing presentation covered in class.

April 5

This week, we reviewed presentation requirements and continued development on password changing and logout features while planning the remaining work for the semester.

We also completed inserting all required values into the database tables.

April 12

This week, we continued developing both the presentation and the project website.

Our time was split between optimizing existing pages and continuing development on unfinished components.

April 19

This week, we focused on structuring our final presentation and assigning speaking roles.

We also continued refining the project website in preparation for the end of the semester.

April 26

This week, we completed the implementation of the logout and profile interfaces and added functionality for users to change their passwords according to project specifications.

We also finalized our PowerPoint presentation in preparation for presenting on April 29.
